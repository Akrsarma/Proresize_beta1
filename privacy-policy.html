Privacy Policy

Your images stay under your control.

This policy explains what ProResize does with your images, what information may be processed, and how privacy is handled.

Effective Date

Privacy policy for the website and extension.

Effective date: May 24, 2026

ProResize is designed to provide simple image resizing, compression, and cropping tools while keeping user privacy as an important priority. This privacy policy explains how ProResize currently handles user data on the website and how the browser extension is treated separately.

1. Information ProResize processes

When you use the main ProResize website without logging in, your selected images are processed in your browser so the tool can resize, compress, crop, or optimize them. The core image tools are intended to work locally on your device.

ProResize does not require you to create an account in order to use the main image tools. However, the website currently offers optional login and history features for the college project version of the service.

2. Website image handling

For normal website use, ProResize aims to process selected images locally on your device within the browser environment. This means image editing actions are intended to happen on-device and not through remote storage for standard use.

If you choose to use optional account or history-related features during this college project phase, limited history metadata may be stored with Firebase services. This metadata can include details such as the image name, tool used, output format, sizes, dimensions, and related timestamps.

You remain responsible for the images you choose to process and for how you use exported files after download.

3. Optional account data

If you create an account or sign in through the website, ProResize may store limited account-related data such as your name, email address, login provider, history records, and related timestamps. This is used only to support optional login and saved history features.

History records are intended to store activity metadata only. They are not intended to store the processed image file itself as part of the current history feature.

These account and history features are currently included for the college project version of ProResize. They are temporary project features, and the data approach is planned to be reviewed and improved before July 2026.

4. Browser extension policy

The ProResize browser extension is treated separately from the website account/history feature described above. The extension is intended to remain 100% local, and its processing is not affected by the website login/history system.

In the intended extension workflow, images are processed locally on the user's device and are not uploaded to ProResize servers as part of the extension's normal operation.

5. Cookies, local storage, and preferences

ProResize may use browser storage features such as local storage to remember interface preferences like theme settings or temporary interface choices. This is used to improve usability and is not intended for cross-site tracking.

These browser storage features are not intended to act as the main saved-history system for signed-in account history.

6. Third-party services

The website may use third-party services and hosted assets such as Firebase, hosted fonts, and other standard web resources. Those providers may process technical request data according to their own privacy practices.

7. Data security

ProResize is designed to minimize unnecessary data exposure by keeping the core image tools browser-based. However, optional account and history features may involve cloud services during this college project phase. While reasonable care is taken, no internet-based service can guarantee absolute security in every situation.

8. Temporary college project notice

The current website login, account history, and any related cloud data storage are part of a college project stage. This setup is temporary and is expected to be reviewed, reduced, or improved before July 2026.

This notice does not apply to the intended privacy model of the browser extension, which is planned to remain fully local and not dependent on website cloud history features.

9. Changes to this policy

This privacy policy may be updated from time to time to reflect feature changes, legal requirements, project deadlines, or service improvements. Any updates will be published on this page with a revised effective date.

10. Contact

If you have questions about this privacy policy or how ProResize handles privacy, you can contact: support@proresize.com
